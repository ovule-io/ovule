# Native dependency license supplements

The listed crates.io packages omit a standalone license file. Texts were obtained
from the exact upstream Git commit in `.cargo_vcs_info.json`, retaining relevant
ancestor license/notice files. Each supplement is keyed by crate name and version;
upgrades require a fresh review. Where no upstream text is present and the package
explicitly offers Apache-2.0, the Apache-2.0 alternative is selected and its standard
text is included, with the upstream SPDX declaration recorded in the supplement.

Original upstream copyright notices are retained. These materials are not covered
by Ovule's project license. The collector never downloads replacement licenses or
invents attribution automatically during a build.
