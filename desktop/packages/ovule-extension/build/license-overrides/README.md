# Upstream license snapshots

These npm distributions omit a standalone license or embed another package.
The build maps these reviewed snapshots to pinned dependency versions and rejects
unknown versions. react-remove-scroll-bar's npm gitHead is unavailable upstream;
its publisher's MIT license is retained as a reviewed supplement instead.

- `saxes-5.0.1.txt`: https://raw.githubusercontent.com/lddubeau/saxes/v5.0.1/LICENSE
- `core-js-3.45.0.txt`: https://raw.githubusercontent.com/zloirock/core-js/v3.45.0/LICENSE
  (embedded in `pdfjs-dist` 5.4.149).

Retain original copyright notices and license text. On upgrades, review the
corresponding upstream version and update the supplement mapping; do not insert
a generic license template in place of the upstream text.

- `react-remove-scroll-bar-2.3.8.txt`: https://raw.githubusercontent.com/theKashey/react-remove-scroll-bar/8ca9ba5ea52de03308fe8ced94f7b159a44d28ff/LICENSE

- `remark-math-6.0.0.txt`: https://raw.githubusercontent.com/remarkjs/remark-math/d5d0660b150810a535bbb07eac6cc96a4510aa24/license
